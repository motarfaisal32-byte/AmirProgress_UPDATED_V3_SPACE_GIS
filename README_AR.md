# AmirProgress – تحديث المشروع

## التحديثات المضافة
- تغيير اسم التطبيق والعناوين إلى AmirProgress.
- إضافة شعار AmirProgress أعلى شعار MARAMER.
- التقارير تتضمن البيانات الوصفية (Attributes) والإحداثيات المكانية (Coordinates) من طبقات الخطوط والمناهل.
- إضافة أدوات لإضافة منهل، إضافة خط/فرعة، حذف العنصر المحدد، حفظ تعديلات GIS محليًا، وتصدير GeoJSON محدث.
- التعديلات تُحفظ في LocalStorage على الجهاز، ويمكن تصديرها كـ GeoJSON.

> ملاحظة: الحفظ المحلي لا يكتب مباشرة داخل ملفات Shapefile الأصلية؛ يلزم تحويل/تصدير GIS خارجي إلى Shapefile عند الحاجة.


## تحديث V3 — لوحة فضائية وتقارير زمنية وتعديل GIS واقعي
- استبدال شعار MARAMER بخلفية شفافة مع الحفاظ على ألوان الشعار الأصلية.
- واجهة Dashboard داكنة بطابع فضائي مع مؤشرات تقدم دائرية وأشرطة موزونة بطول الشبكة.
- الإنجاز الأولي يعتمد على حالة GIS المصدر: Asbuilt/منفذ = 100%، والتنفيذ الجاري = 50% ما لم توجد بيانات تقدم محفوظة.
- إضافة منهل جديد مع خصائص GIS أساسية وحماية من التكرار.
- إضافة خط جديد بشرط الارتباط بمنهلين موجودين، مع حساب الطول الجيوديسي والميل والربط Upstream/Downstream تلقائيًا.
- تعديل مسار الخط مع نقاط قابلة للسحب، وتثبيت أطراف الخط على المناهل عند الاقتراب منها.
- منع حذف منهل مرتبط بخطوط للحفاظ على طوبولوجيا الشبكة.
- سجل زمني لكل عملية حفظ للتقدم والاستلام.
- تقارير الإنجاز: يومي + شهري + 3 أشهر + نصف سنوي + 9 أشهر + سنوي + كل البيانات، مع اختيار تاريخ التقرير اليومي.
- تصدير PDF / Excel / CSV / GeoJSON / DXF، مع الحفاظ على البيانات المكانية والوصفية.
